For held-out validation of the inharmonicity head without editing `validate()` or `render_fixed_set` yet, I propose we add a separate validation step that runs the fixed validation patches through the dataset's `process_phrase` pipeline (using the same configurations). We can collect the ground-truth inharmonicity values for the held-out set and compare the model's MSE against a constant-prediction baseline (e.g., predicting the global training mean).
