# Findings

*Companion to **[Hands Inside the Instrument](../README.md)** and the **[Control-Methods Sourcebook](../CONTROL_METHODS_SOURCEBOOK.md)**.*

The book builds intuition and ends each chapter with an open question. The Sourcebook ranks the methods to reach for. **This folder is what happens after you reach** — dated notes from actually reading a paper closely, checking it against our code, or running a probe. A finding may *supersede* a Sourcebook line (e.g. "paper-only, reimplement it" → "we already have a near-faithful port; here are the three gaps").

Each note keeps the house rule: where a closer look corrected an over-optimistic claim, the **corrected** version is kept, not the cheerful one. Each ends by opening the next question rather than closing one.

## Notes

- [2026-06-23 — Curated-reference rewards & the SAME-L steerability map](2026-06-23-curated-reference-rewards-and-the-same-l-steerability-map.md) — three runs: Audiobox aesthetics are a genre-biased **collapse-floor, not a reward**; a **curated reference set is a genre-neutral reward** (MERT-separation AUC 0.999 vs default output, ~0.87 within-genre at layers 5–6); and the **measured SAME-L steerability map** (spectral easy ~0.8, rhythm hard — **downbeat R² 0.16**, which *explains the riffer's rhythm-transfer failure*). Plus the multi-band MERT-conditioner design — and the gating probe, now **run**: **MERT exposes rhythm where SAME-L hides it** (beat 0.36→**0.83**, onset →0.71, downbeat →0.39, all at MERT layers ~1–6; spectral/chroma show no MERT gain). **Then corrected (§6):** a **temporal 1D-CNN head on the latent matches/beats MERT** (beat 0.86, onset 0.81, downbeat 0.58) — the latent never hid rhythm, the per-frame *linear* probe just couldn't see it. So **you don't need MERT for rhythm — build a temporal LatCH head** (no finetune); MERT's niche narrows to the reference-*style* reward. Lesson: LatCH heads for temporally-structured features must be temporal, not per-frame. Advances Sourcebook §Ch13 (relational head) / §Ch8 (conditioner).

Advances Sourcebook §Ch9/10 entry #3 (FlowEdit + AudEdit).
