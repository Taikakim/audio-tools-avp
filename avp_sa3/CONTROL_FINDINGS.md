# SA3 Control — Findings (full list)

A neutral, complete list of the components surfaced by the cross-domain control-methods sweep — for you to judge relevance. No ranking, no roadmap. Each entry: what it is · domain · maturity · the SA3-relevant note · source. Maturity = (validated) [demonstrated, often in a sibling/related setting] · (plausible) [reasoned adaptation, untested for us] · (speculative) [no direct precedent]. The prioritized view with a suggested order lives in the companion `avp_sa3/RESEARCH_RADAR.md`.

**Provenance:** 55 candidates found across 8 web-search lanes; 46 kept after re-fetch verification (9 dropped as unverifiable or judged non-transferable). Several entries cite very recent (2026) papers found via live search — spot-check arXiv IDs before relying on them. SA3 recurring constraints noted per entry: guidance/backprop must be **fp32**; latents are **1D temporal** (spatial-mask tricks become temporal windowing); **descending-t Euler**; **rectified flow**, not DDPM.

---

## Guidance & sampling (hook b — the CFG/velocity update rule)

- **CFG-Zero\*** — _image RF-DiT (SD3/Flux/Lumina) · validated_ — per-step optimal scalar on the CFG velocity + zero-init of the first ODE step; fixes early-step (t≈1) misdirection. SA3: near-one-line change in `sampling.py`; the zero-init targets the same place FIFO frame-boundary noise misbehaves. https://arxiv.org/abs/2503.18886
- **APG (Adaptive Projected Guidance)** — _image diffusion · validated_ — split CFG diff into parallel/orthogonal parts, down-weight the parallel (oversaturation) term, add negative momentum. SA3: **already partly in `dit.py`** (`apg_project` + `apg_scale`); only the negative-momentum term is missing. https://arxiv.org/abs/2410.02416
- **ERG (Entropy Rectifying Guidance)** — _DiT/MMDiT · validated_ — temperature on the self-attention softmax gives a "weak prediction" with no separate model; 2 NFE/step. SA3: DiT-native, single dial schedulable across t; composes with APG. https://arxiv.org/abs/2504.13987
- **TPG (Token Perturbation Guidance)** — _SD3 · validated_ — guidance contrast from a second pass with norm-preserving token shuffle; no uncond model; works fully unconditional. SA3: shuffle is index-agnostic (1D tokens fine); unconditional mode = guidance for LatCH-only, prompt-free generation. https://arxiv.org/abs/2506.10036
- **Autoguidance** — _image diffusion · validated_ — replace the CFG uncond branch with a forward pass through a *weaker* checkpoint of the same model. SA3: candidates already ship (`small-music`, `medium-base`, an early LoRA step); better direction than the null-prompt average; cost = two checkpoints in VRAM. https://arxiv.org/abs/2406.02507
- **Rectified-CFG++** — _RF (NeurIPS 2025) · validated (no audio)_ — predictor-corrector guidance derived for RF; keeps the ODE on-manifold and invertible. SA3: fixes high-CFG mode-collapse *and* restores inversion fidelity (helps RF-Solver separation); corrector must be re-derived for SA3. https://arxiv.org/abs/2510.07631
- **TFG (Unified Training-Free Guidance)** — _meta-framework · validated_ — unifies DPS/MPGD/FreeDoM/LGD/UGD into 4 axes (mean, variance, smoothing, recurrence) + hyperparameter search. SA3: systematizes LatCH's hand-tuned gain; `latch_guided.py` already implements the RF adaptation. https://arxiv.org/abs/2409.15761

## Latent-nudge & test-time optimization (hooks c, f — steer/optimize the latent toward an audio target)

- **FreeDoM** — _image/diffusion · validated_ — backprop any pretrained time-independent network through x0-hat to the noisy latent; no head training. SA3: skips LatCH's head-training (plug an MIR network as the energy); fp32 + enable_grad. https://arxiv.org/abs/2303.09833
- **MPGD (Manifold-Preserving Guided Diffusion)** — _image LDM · validated_ — wrap any classifier with an AE-shortcut manifold projection (decode z0-hat, compute loss, gradient through the decoder). SA3: uses SAME-L's own decoder so CLAP/beat-tracker/Audiobox become guidance losses without off-manifold drift; 3.8× faster than naive. https://arxiv.org/abs/2311.16424
- **FlowDPS** — _latent RF-DiT (SD3-class) · validated_ — DPS posterior sampling adapted to RF via flow-Tweedie; measurement gradient on the clean branch per Euler step. SA3: "measurement" = any differentiable audio feature; respects flow geometry; backprop through SAME-L → fp32. https://arxiv.org/abs/2503.08136
- **DITTO / DITTO-2** — _music diffusion · validated_ — optimize initial noise x_T against a differentiable feature loss (melody/intensity/structure/CLAP); DITTO-2 distills a 1-step surrogate for 10–20×. SA3: most complete audio test-time-opt recipe; base works with gradient checkpointing; DITTO-2 needs an SA3 consistency surrogate (hard). https://arxiv.org/abs/2401.12179 · https://arxiv.org/abs/2405.20289
- **DAS (Diffusion Alignment as Sampling, SMC)** — _diffusion · validated_ — Sequential Monte Carlo: N trajectories, per-step reweight by a tempered reward, resample; avoids reward over-optimization. SA3: black-box rewards (onset, beat-grid corr, LUFS); needs SDE-ification of the Euler ODE; N=8–16 feasible at 16 GB sequentially. https://arxiv.org/abs/2501.05803
- **TreeG (tree search over denoise steps)** — _symbolic music · validated_ — propose N continuations/step, score each on x0-hat, keep K best, branch. SA3: non-differentiable rewards OK; branch at intermediate sigma, score a LatCH head; cost = branching × DiT passes. https://arxiv.org/abs/2502.11420
- **DOODL** — _image · validated_ — full-chain backprop via an invertible (EDICT) process at O(1) memory; any frozen classifier on x_T. SA3: EDICT's constant memory is DDIM-specific (doesn't port to RF) — substitute an RF-reversible integrator or gradient checkpointing. https://arxiv.org/abs/2303.13703

## Adapters & weights (hooks a, d — finetune/LoRA/RL beyond plain LoRA)

- **Concept Sliders** — _image LoRA · validated_ — tiny LoRA on contrastive prompt pairs + preservation prompts isolates a *single continuous axis*; sliders compose linearly. SA3: drop-in to the LoRA API; one slider per MIR feature; modulate with `set_lora_strength`. https://arxiv.org/abs/2311.12092
- **VeRA** — _PEFT · validated_ — one frozen shared random low-rank pair; train only tiny per-layer scaling vectors; 10–100× fewer params than LoRA. SA3: cuts finetune cost; loader needs only the RNG seed; composition = vector addition. https://arxiv.org/abs/2310.11454
- **FreeSliders** — _**Stable Audio Open** · validated_ — training-free sliders: `v + μ·(v_pos − v_neg)` from 3 passes/step; benchmarked on Stable Audio Open, 10 attributes, +17% vs trained sliders. SA3: zero training, one extra pass over CFG; composes with LoRA+FIFO. https://arxiv.org/abs/2511.00103
- **MuseControlLite** — _**Stable Audio Open** · validated_ — decoupled cross-attention adapters **with RoPE** on a frozen music DiT for time-varying control (melody/rhythm/dynamics); 85M params (~8%). SA3: the LatCH-phase-2 recipe; `latents_sa3/*.TIMESERIES.npz` is ready training data; RoPE shown essential. https://arxiv.org/abs/2506.18729
- **GLIGEN gated self-attention** — _image · validated_ — insert gated (tanh, init-0) self-attention layers to ingest structured non-text tokens; freeze original cross-attn. SA3: inject a second modality (beat-grid, reference SAME latents, MIR timeseries) per frame; needs an MLP projector + training. https://arxiv.org/abs/2301.07093
- **DDPO** — _diffusion RL · validated_ — each denoise step = an action; score the final audio with any reward; policy-gradient (LoRA-able). SA3: non-differentiable rewards; original is DDPM-only → add SDE noise to RF rollouts or reward-weighted SFT. https://arxiv.org/abs/2305.13301
- **Flow-GRPO** — _flow-matching RL (SD3.5/FLUX) · validated_ — GRPO for flow models: sample K/prompt, group-normalize advantages, update LoRA, no critic. SA3: cheaper than DDPO; needs ODE→SDE + audio reward fns; K-sampling expensive at 16 GB → small-music-base/short crops. https://github.com/yifan123/flow_grpo

## Per-frame sigma & long-form (hooks b, c — break the single global timestep)

- **FIFO-Diffusion (latent partitioning + lookahead denoising)** — _video diffusion · validated_ — narrower per-block sigma ranges + update only the noisiest half so frames denoise against clean-enough neighbours. SA3: closes the diagonal-denoising train/inference gap with no finetune (~50 LOC); partitioning ≈ `build_slot_sigmas()`; lookahead not yet in our prototype. https://arxiv.org/abs/2405.11473
- **Rolling Diffusion** — _fluid dynamics (modality-agnostic) · validated_ — position-relative sigma ramp (later positions = higher sigma); window slides, one clean frame/step. SA3: drop-in swap for our linear ramp; inference-only use is heuristic (not trained with it). https://arxiv.org/abs/2402.09470
- **Deep Forcing (Deep Sink + Participative Compression)** — _streaming video · validated_ — training-free KV-cache mgmt: persistent anchor frames with temporal RoPE phase re-alignment; prune cache by recent attention weight. SA3: RoPE-encoded → ports directly, training-free; anchors style/key/energy; testable on `medium` now. https://arxiv.org/abs/2512.05081
- **Diffusion Forcing** — _sequence diffusion · validated_ — train with independent per-token noise levels (VLB over subsequences) → causal/AR generation + arbitrary subsequence conditioning. SA3: the principled training objective our FIFO prototype approximates; needs RF re-derivation + a finetune from `medium-base`. https://arxiv.org/abs/2407.01392
- **Rolling Forcing** — _streaming video · validated_ — rolling-window sigma + bidirectional in-window attention + dual-tier KV cache (recent + initial anchor as attention sink) with dynamic RoPE re-align. SA3: lowest drift at real-time; sigma+in-window-attn are sampler-only, the dual KV anchor needs a short finetune + a causal mask (SA3 has none by default). https://arxiv.org/abs/2509.25161

## Interpretability → steering directions (hooks c, e — read internal structure, turn it into a knob)

- **TADA (activation steering on audio-DiT bottleneck)** — _**Stable Audio Open** · validated_ — activation patching finds a small consecutive-layer "semantic bottleneck"; inject Contrastive Activation Addition (mean-difference) vectors there at inference; no retraining. SA3: validated on the sibling model (bottleneck ~layers {11,12}/24; vocals/tempo/genre/instruments); ~256 contrast pairs; reportedly beats LoRA on attribute precision. https://arxiv.org/abs/2602.11910
- **SAE on SAME-L latents** — _audio VAE (DiffRhythm/EnCodec) · validated; SAME-L is extrapolation_ — train a sparse autoencoder on the latent corpus to split polysemantic dims into monosemantic acoustic features (pitch/amplitude/timbre) → linear knobs. SA3: we have the dataset (5400 crops, hours-not-days); onset features unproven. https://openreview.net/forum?id=5fsYFQzzMX (arXiv 2510.23802)
- **DiffMean** — _MusicGen (AR) · validated_ — difference-in-means steering vectors from hidden states; one-to-all injection with scalar λ. SA3: discover linear BPM/key/density directions; replace EOS anchor with conditioning-token/latent pooling, inject across steps. https://arxiv.org/abs/2504.04479
- **SHIFT** — _flow DiT (joint-attn) · validated_ — dual injection: a vector into the text-encoder pooled embedding + one into DiT text-token activations, with cosine-sim dynamic per-step scaling. SA3: hook (a) maps cleanly to T5-Gemma; hook (c) needs re-derivation onto SA3's separate cross-attn; cheap mean-difference vectors. https://arxiv.org/abs/2604.09213
- **SMITIN (self-monitored intervention)** — _MusicGen · validated_ — logistic-regression probes on individual attention heads; shift along the probe direction with a self-monitoring loop that backs off on detected incoherence. SA3: the self-monitor directly addresses LatCH oversteer at high gain; we have the labels; re-ground the monitor across T latent positions. https://arxiv.org/abs/2404.02252
- **TIDE (temporal-aware SAE on DiT activations)** — _image DiT · validated; no audio_ — timestep-conditioned SAE (scale/shift from the model's AdaLN) finds monosemantic features evolving across denoise steps; erase/scale/transfer. SA3: AdaLN fits natively; hypothesis early-t structural / late-t detail; post-hoc, no retraining; penultimate block the sweet spot. https://arxiv.org/abs/2503.07050

## Attention editing & inversion (hooks a, b, c — structure-preserving edits, prompt fidelity, faithful inversion)

- **FireFlow** — _RF (Flux) · validated_ — second-order RF ODE solver at Euler cost by reusing the velocity across midpoints; 8-step inversion, 3× faster. SA3: drop-in for the inversion in `sa3_zerosep_rf.py`; tightens the 0.23 round-trip; a few dozen LOC. https://arxiv.org/abs/2412.07517
- **Attend-and-Excite** — _image · validated_ — per-step latent nudge maximizing the minimum peak cross-attention over subject tokens. SA3: fixes prompt-token neglect ("kick, bass, hi-hat" → one missing), arguably worse in audio; 1D T=4096 cross-attn map is a direct analogue. https://arxiv.org/abs/2301.13826
- **MasaCtrl (mutual self-attention)** — _image · validated_ — replace target self-attention K/V with the source branch's; mask from cross-attention (no manual mask). SA3: non-rigid edit it lacks (preserve timbre, reshape content); apply to a suffix of blocks; 2× cost. https://arxiv.org/abs/2304.08465
- **KV-Edit (background KV injection)** — _MM-DiT · validated_ — cache unedited-region KV, concatenate with foreground queries throughout denoise; O(1) memory, inversion-free. SA3: hard-anchors unchanged context in inpaint/continuation (stronger than our boundary-hoping sliding-window); 2D mask → 1D temporal. https://arxiv.org/abs/2502.17363
- **RF-Inversion via LQR (stochastic SDE)** — _Flux RF · validated_ — recast RF inversion as optimal control → reverse rectified-SDE; an η-dialled stochastic term absorbs per-step error. SA3: fixes the documented sign/blow-up at t→1; replaces the ad-hoc η in `sa3_zerosep_rf.py` with a principled one. https://arxiv.org/abs/2410.10792
- **RF-Solver + RF-Edit** — _RF · validated_ — high-order Taylor RF inversion + inject self-attention K/V from the inversion pass into editing. SA3: gives FlowEdit a P2P-style structure memory (for separation/stem-edit); injection needs forward hooks on DiT self-attn (already exposed); open Q whether audio self-attn carries structure. https://arxiv.org/abs/2411.04746
- **FluxSpace** — _Flux (joint-attn) · validated_ — inference-time edit directions from attention outputs via orthogonal projection against the null condition; coarse/fine controls. SA3: a LatCH-like direction without a trained head; re-engineer extraction onto SA3's separate cross-attn; spatial → temporal. https://arxiv.org/abs/2412.09611
- **Stable Flow (vital-layer identification)** — _DiT · validated_ — residual-bypass ablation ranks which DiT layers are "vital"; inject features only there. SA3: answers "which layers?" (no UNet hierarchy to guess) via a one-time offline ablation with an audio perceptual proxy (CLAP/SAME-cosine/mel-MSE). https://arxiv.org/abs/2411.14430
- **JASCO (information bottleneck + temporal pooling)** — _music diffusion · validated_ — pass time-varying conditions through an IB + temporal average-pool before injection → a leakage dial against copy-not-guide. SA3: an over-conditioning regularizer for noisy MIR targets; recalibrate pooling for the 10.767 Hz grid; JASCO injected by concatenation (cross-attn was worse in its ablation). https://arxiv.org/abs/2406.10970
